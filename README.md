# Titanic Survival Prediction

First ML project — predicting Titanic passenger survival using multiple classification models.

## Setup
1. Create venv: `python -m venv venv`
2. Activate: `venv\Scripts\activate`
3. Install deps: `pip install -r requirements.txt`
4. Download data from Kaggle: https://www.kaggle.com/c/titanic/data → place in `data/`

## Project structure
- `notebooks/` — exploratory data analysis
- `src/` — reusable scripts (data cleaning, model training)
- `data/` — raw datasets (not tracked in git)
